# Code of conduct

This project is a place to work on software together. Everyone taking part is expected to:

- Be respectful and assume good intent. Disagree about the work, not the person.
- Keep it on topic and public. Questions and decisions belong in issues and discussions, where others can find them.
- Protect privacy. Do not post anyone's messages, contact details or account data, including your own by accident.

Not acceptable: harassment, insults, discriminatory language, sexual content, threats, publishing private information,
and repeated off-topic or automated posting.

The maintainer may edit or remove comments, close threads, and block accounts that break these rules. To report a
problem privately, use the maintainer contact on the repository owner's GitHub profile.
